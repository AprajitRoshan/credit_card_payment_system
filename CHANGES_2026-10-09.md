# Changes — 9 Oct 2026

## 1. Fraud detection (verified end-to-end)

- New `fraud` Django app: `FraudLog` model, `GET /api/fraud/logs/`, `PATCH /api/fraud/logs/{id}/review/` (audit-logged).
- FastAPI `app/services/fraud_service.py`: rules for multiple high-value payments, rapid payments, different device and different location within 10 minutes.
- Flagged payments set `fraud_status=FLAGGED`, store a fraud log, and email the customer (`alert_sent` recorded).
- **Fixed:** Django was missing the `fraud_status` / `fraud_reason` columns FastAPI writes to (migration `transactions/0004`, safe if the columns already exist).
- **Fixed:** fraud time window compared UTC against MySQL local time; timestamps are now written in UTC.
- **Fixed:** payments were accepted on blocked or unknown cards.
- **Fixed:** re-processing a payment returned 404; now 400.
- Payment page sends device id, time zone (location) and category.

## 2. Frontend analytics charts

- New `/analytics` page: 6-month spending trend (line), category expenses (bar), transaction status (pie/donut), per-card credit utilization, CSV/PDF export.
- Chart colours validated for colour-blind safety in light and dark mode.
- Chart pages are lazy-loaded (initial bundle 906 KB → 458 KB).

## 3. Monitoring

- Django and FastAPI middleware log response time, status and errors for every API call (`monitoring_apirequestlog`, `logs/api.log`, `X-Response-Time-ms` header).
- `GET /api/health/` (Django) and `GET /health` (FastAPI).
- `GET /api/admin/system-health/` aggregates status, avg/P95 response time, error rate, hourly traffic, slowest endpoints, recent errors.

## 4. Admin dashboard

- System Health panel (auto-refresh 30 s) and Fraud Detection Log panel with Confirm / Dismiss / Reopen.
- Controls follow the user's role (export = Admin only, fraud review = Admin/Support).

## 5. Analytics export

- `GET /api/transactions/analytics/export/csv/` and `/pdf/`.
- **Fixed:** PDFs crashed outside Windows (hard-coded `C:\Windows\Fonts\arial.ttf`); new `statements/pdf_fonts.py` works on Windows, Linux/Docker and macOS.

## 6. Testing

- Django: 57 tests (RBAC, audit log, fraud, search, analytics, exports, monitoring).
- FastAPI: 31 tests, 95% coverage (isolated SQLite DB, mocked emails).
- End-to-end: `scripts/e2e_test.py`, 39/39 checks passed against running services.
- **Fixed:** invalid dates such as `2026-13-40` returned 500 instead of 400.
- **Fixed:** Transactions page read the paginated API response as an array, so the list never rendered; added date range, card search, fraud filter, sorting and pagination.

## 7. Cleanup and docs

- Roles seeded by migration; new sign-ups get `CUSTOMER`; `python manage.py assign_role <user> <ROLE>`.
- `/api/auth/me/` returns `role`; dashboard admin link uses role.
- Configurable `ALLOWED_HOSTS`, `EMAIL_BACKEND`, `FASTAPI_HEALTH_URL`, `DJANGO_API_URL`; Docker Compose healthchecks and inter-service URLs.
- `.env.example` files; Django `requirements.txt` converted from UTF-16 to UTF-8.
- Removed duplicate `credit_limit_notification.py`; FastAPI dashboard query no longer MySQL-only.
- README, Postman collection and OpenAPI schema updated.
